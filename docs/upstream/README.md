# Upstream BetterSolano documents

These files come from the [BetterSolano](https://github.com/BetterSolano/bettersolano) project
that BetterBukidnon was built from. They are kept unchanged for reference and describe
Solano, Nueva Vizcaya, and BetterSolano's plans, not Bukidnon:

- `MIGRATION.md`: BetterSolano's plan to move from static HTML to React + TypeScript
- `migration/`: announcement and release notes for that migration
- `rollout/`: BetterSolano's guide for rolling the template out to other LGUs, including the
  Kapwa design values checklist

The rollout guide's design and accessibility standards still apply to this project. For
current BetterBukidnon documentation, start at [../README.md](../README.md).
